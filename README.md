# 📦 Система учетов заказа(order managment system)
Настольное графическое приложение на Python (**tkinter** / **ttk**)для удобного отслежование заказов и редактиврование статусов и управление заказами.

---

# 🛠️Технологии и требования

* **Язык програмирования** Python 3.12
* **Графический интерфейс** `tkinter` , `ttk` - (встроены в стандартную библеотеку Python)

---

## 📁 Структура проекта

```text
project/
│
├── order_model.py       # Модель данных (Order, OrderStatus)
├── order_manager.py     # Бизнес-логика (OrderManager)
├── order_app.py         # GUI (OrderApp) + точка входа
│
├── README.md            # Документация
└── requirements.txt     # Зависимости (только tkinter, встроен)
```

## 🎮 Функциональные возможности
- Создание, редактирование, удаление заказов
- Отслеживание статусов (Новый → В обработке → Отправлен → Доставлен / Отменен)
- Добавление заметок к заказам
- Просмотр статистики

---
## 💻 Запуск проекта
1.Убедитесь, что все три файла(`order_mode.py`, `order_manager.py`, `order_app.py`)находяться в одной папке
2.Откройте терминал/командную строку в этой директории 
3.Запустите приложение командной:

```bash
python order_app.py
```
